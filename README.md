# homebrew-tunneldeck

Homebrew tap for [TunnelDeck](https://github.com/ff2248/TunnelDeck), a macOS menu bar manager for SSH local port forwards.

```bash
brew tap ff2248/tunneldeck
brew trust ff2248/tunneldeck   # Homebrew loads third-party taps only after you trust them
brew install --cask tunneldeck
```

`Casks/tunneldeck.rb` is updated automatically each time TunnelDeck publishes a release.
